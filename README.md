Ohm's Law and Power Calculator

What it does

This is a Python program that calculates voltage, current, resistance and electrical power using Ohm's Law formulas. It allows users to select the calculation they want and displays the result with the correct unit.

How to run it

Install Python 3, then run:

python ohms_law.py

Sample output

What would you like to calculate?

1. Voltage
2. Current
3. Resistance
4. Power

Example:

Enter voltage (V): 12

Enter resistance (Ohms): 6

Current = 2.00 A

My own twist

I added a calculation history feature that stores previous results. Users can view their previous calculations without having to calculate them again.
